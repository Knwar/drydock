# Brief Templates

## Daily brief

```markdown
# [Day, date]

Sources: inbox, calendar, commitments, notes. [Name any source you could not reach.]

## Top 3
1. [Thing] — why it matters today. First step: [step].
2. [Thing] — why. First step: [step].
3. [Thing] — why. First step: [step].

## Schedule
- 09:00–09:30  [Event] — prep: [what, by when] / [no prep]
- 10:00–11:00  [Event] — CONFLICT with [event]. Suggest: [fix]
- 11:00–12:00  [Event, in person at X] — only [N] min to get there from [Y]
- [Time zones shown in local time; missing links/locations/agendas flagged inline]

## Decisions waiting on you
- **[Decision]** — options: A / B. Recommend: [A], because [reason]. If you wait: [cost].

## Deadlines
- Overdue: [item] (was due [date]) — [proposed action]
- Today: [item]
- Next 3 days: [item] ([date])

## Replies ready
1. [Sender] — [subject] — [one-line summary]. Draft below. [Urgency reason]
2. ...
Flagged (no draft): [sender] — [subject] — why flagged

## What changed since last brief
- [New thread that matters / meeting moved / item finished / new commitment from someone]

## FYI
- [One line each]
Ignored: [N] newsletters, [N] notifications, [N] promos.
```

Rules: one screen. Top 3 are outcomes, not "check email". Every decision has a recommendation. Drafts appear after the brief, each under its thread's subject line.

## Commitment list entry

```
- [What] | owner: [user / name] | for: [name] | due: [date] | from: [email / meeting / note, date] | status: open / waiting / done / dropped
```

## Weekly review checklist

**Week of:** ______  **Timebox:** 60–90 minutes

### Get clear
- [ ] 1. Collect loose inputs: notes, screenshots, downloads, receipts, voice memos, into one inbox
- [ ] 2. Process every inbox to zero: clarify each item into next action, project, waiting-for, someday/maybe, reference, or trash (do it now only if under two minutes)
- [ ] 3. Mind sweep: capture every commitment or nagging thought still in the user's head

### Get current (all five; skip only with a stated reason)
- [ ] 4. Next-action lists: mark done, prune dead, surface stuck (stuck items need a decision)
- [ ] 5. Last week's calendar: missed commitments and meeting follow-ups become captured items
- [ ] 6. Next two weeks' calendar: create prep actions now
- [ ] 7. Waiting-for list: chase (draft the nudge), re-date, or drop each item
- [ ] 8. Project list: every active project has exactly one next action; no next action means stalled or someday

### Get creative
- [ ] 9. Someday/maybe: activate, keep, or kill each item
- [ ] 10. New ideas: capture them while the head is clear

### Close
- One next action for the coming week: ______
- Skipped steps and why: ______ (these go first next week)

A lapsed habit restarts with a shorter pass and no guilt. The review is maintenance, not judgment.

## Delegation brief

```markdown
**To:** [name]   **From:** [user]   **Due:** [date]   **Check-in:** [date]

**Goal**
[The outcome in one sentence, and why it matters.]

**Context**
- Background: [what led here]
- Constraints: [budget, time, must/must-not]
- Links and people: [docs, contacts, who else is involved]
- Already tried: [what didn't work, if anything]

**Done means**
- [ ] [Checkable criterion]
- [ ] [Checkable criterion]

**You can decide:** [scope of the teammate's authority]
**Check with me before:** [what needs the user]
```

A good delegation brief can be acted on without a follow-up question. If the teammate would need to ask "what does done look like?", the brief isn't finished.
