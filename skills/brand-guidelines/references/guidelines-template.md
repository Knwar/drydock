# Brand guidelines template

Fill every section; delete a section only if the product genuinely does not need it yet (say so in "Open questions"). Keep each section to what changes a decision.

The voice-attribute and tone-by-context tables follow the shape of the universal framework in alirezarezvani/claude-skills brand-guidelines (MIT).
