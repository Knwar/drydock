## Idea scoring

Adapted from coreyhaines31/marketingskills content-strategy (MIT). Score each factor 1 to 10, multiply by the weight, and sum.

| Idea | Pillar | Audience impact (40%) | Fit with the goal (30%) | Discoverability (20%) | Effort, inverted (10%) | Total |
|------|--------|-----------------------|-------------------------|-----------------------|------------------------|-------|
| | | | | | | |

- **Audience impact**: how often the topic comes up, how many in the audience face it, how strongly they feel it.
- **Fit with the goal**: does it serve the publication's promise and goal; can the person add something others can't?
- **Discoverability**: search or social interest, shareability, whether it's growing.
- **Effort, inverted**: high score = cheap to make with existing knowledge and assets.

For a book, replace this with a chapter list in reading order; for a fiction serial, with the outline.

A starting mix for blogs and newsletters (from the same source): roughly 60% evergreen/searchable, 30% shareable (opinion, original data, stories), 10% experimental. Adjust to the goal; it is a starting ratio, not a rule.
